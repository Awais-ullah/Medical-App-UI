# 🏥 Medical App UI

A modern and user-friendly **Medical App UI built with Flutter**, designed to provide a simple and convenient healthcare experience. This project focuses on clean interface design, easy navigation, and responsive layouts.

## ✨ Features

* 🏠 Home Dashboard
* 👨‍⚕️ Doctor Listing
* 🔍 Search Doctors
* 📅 Appointment Booking UI
* 🩺 Doctor Details
* 🏥 Hospital Information
* 💊 Medicine Section
* 📋 Appointment History
* 👤 User Profile
* 🔔 Notifications UI
* 📱 Responsive Design
* 🎨 Clean & Modern UI

## 🛠️ Technologies Used

## 🚀 Getting Started

### Prerequisites

Make sure you have:

* Flutter SDK
* Dart SDK
* Android Studio or VS Code
* Android Emulator or Physical Device

### Installation

Clone the repository:

```bash
git clone https://github.com/your-username/medical-app-ui.git
```

Navigate to the project:

```bash
cd medical-app-ui
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
